Project Abstract: 
 
Most real-world documents used in AI systems — research papers, reports, manuals — exist as PDFs. But
extracting them accurately remains a major challenge. In documents with multiple columns, text is often 
read out of order. Tables collapse into meaningless strings of text, losing their row-column structure. 
Formulas are frequently dropped entirely, without any warning. These errors happen silently, at the very 
first step of the pipeline, and quietly affect every AI-generated answer built on top of them. 
This project builds a document-ingestion pipeline that fixes this problem. It recovers the correct reading 
order from complex, multi-column PDFs, and extracts tables and formulas as separate structured elements 
instead of flattening them into plain text — using simple, practical tools like PyMuPDF, pdfplumber, 
Camelot, and Nougat. As a unique addition, the system also tracks the exact page each extracted element 
came from and attaches a confidence score to it, so downstream systems know how much to trust each
piece of information. 
To prove the pipeline actually works — not just looks cleaner — its effectiveness is measured through real 
downstream retrieval accuracy, using Sentence-Transformers and FAISS in a RAG-based retrieval system. 
The complete pipeline is tested across diverse document types to ensure it performs reliably under real-
world conditions, not just in ideal cases.

Plant Disease Detection Using Deep Learning: A Comparative
Study
A. Student, B. Student, C. Student
Department of Computer Science and Engineering
1. Introduction
Crop diseases reduce agricultural yield by nearly twenty
percent every year in India. Farmers in Guntur district
often identify leaf diseases late, which causes heavy
losses to chilli and cotton crops.
This paper compares three convolutional neural
networks for automatic leaf disease classification using
photographs taken in real field conditions.
2. Dataset
The dataset contains 12,000 labelled leaf images
collected from farms across Andhra Pradesh. Images
are divided into 70 percent training, 15 percent
validation and 15 percent testing.
3. Evaluation Metrics
Model quality is measured using accuracy, precision,
recall and the F1 score, defined as follows.
Accuracy = (TP + TN) / (TP + TN + FP + FN)
P = TP / (TP + FP)
R = TP / (TP + FN)
F1 = 2 * P * R / (P + R)
Here TP means true positives, TN true negatives, FP
false positives and FN false negatives.
4. Training Setup
All models were trained for fifty epochs using the Adam
optimizer with a learning rate of 0.001 and a batch size
of 32.

7. Discussion
Although ResNet50 gave the best accuracy, MobileNet
is more suitable for smartphones because it needs only
14 MB of memory. Farmers can therefore run the model
offline in the field without an internet connection.
The inference speed can be estimated using the relation
below, where N is the number of images and T is the
total time in seconds.
FPS = N / T
MobileNet processed about 45 images per second on a
mid-range phone.
8. Conclusion
This study showed that deep learning can detect leaf
diseases with accuracy above ninety percent. Future
work will extend the dataset to include pest damage and
nutrient deficiency symptoms.
